# DeepSeek Usage Dashboard

Дашборд для визуализации статистики использования токенов DeepSeek API. Загружает CSV-файлы с данными и строит интерактивные графики.

## Возможности

- Загрузка CSV и ZIP-файлов со статистикой
- Графики расхода токенов по моделям
- Статистика по API-ключам
- Детализация затрат с учётом кэширования
- Экспорт графиков в PNG
- Тёмная тема

## Использование

Откройте `index.html` в браузере. Загрузите CSV-файл с данными об использовании API — дашборд автоматически построит визуализации.

## Технологии

- Чистый HTML/CSS/JS (без сборщиков)
- [Chart.js](https://www.chartjs.org/) — графики
- [PapaParse](https://www.papaparse.com/) — парсинг CSV
- [JSZip](https://stuk.github.io/jszip/) — работа с ZIP-архивами
